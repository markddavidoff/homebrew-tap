# homebrew-tap

Homebrew formulae for tools by [@markddavidoff](https://github.com/markddavidoff).

```bash
brew install markddavidoff/tap/argo-hold
```

| Formula | Description |
|---|---|
| [`argo-hold`](https://github.com/markddavidoff/argo-hold) | Hold one Argo CD app's auto-sync off while a live change stays applied, then revert it |
